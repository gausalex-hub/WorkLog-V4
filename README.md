# WorkLog V3

Android work/activity log.

## Added in V3
- Monthly calendar with browsing backwards at least two years
- Tap a day to see all entries for that day
- Add entries for past dates
- Edit and delete old entries
- Vacation days
- Sick days
- Work totals separated from vacation/sick-day counts
- Existing GPS, voice dictation, office/outside classification and export/sharing retained

Build with GitHub Actions or Android Studio.
